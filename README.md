# Fokir — Personal Portfolio Website

A personal portfolio website built using HTML5 and CSS3 as a frontend development practice project.

The project focuses on recreating the Fokir website layout while practicing page structure, styling, and responsive web design.

## Built With

- HTML5
- CSS3

## Features

- Personal introduction and hero section
- About section
- Services section
- Portfolio gallery
- Testimonials section
- Blog section
- Contact section
- Responsive layouts using CSS media queries
- Hover effects and CSS transitions

## What I Practiced

- Structuring a multi-section website using HTML
- Styling layouts and components with CSS
- Working with Flexbox and element positioning
- Implementing hover effects and transitions
- Creating responsive layouts with media queries
- Debugging alignment, spacing, and sizing issues
- Recreating a website design from visual references without a dedicated design file

## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## What I Learned

This project helped me develop a better understanding of how HTML and CSS work together to build a complete website.

It also gave me more practice translating visual references into code, making independent layout decisions, and troubleshooting responsive design issues.

## Design Recreation Challenge

This project was based on a website I had previously studied through Route Academy. My goal was to recreate the design using HTML and CSS while relying on the original website as a visual reference rather than having a dedicated UI/UX design file.

One of the main challenges was estimating spacing, margins, padding, element sizes, and alignment by visually inspecting the original website and adjusting my CSS accordingly.

This process helped me improve my attention to detail, develop my visual judgment, and better understand how to translate a design into code.
